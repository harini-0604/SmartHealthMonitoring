MAIN WORKFLOW
=============

Camera
  |
  +--> Person Detection
  +--> Pose Detection
  +--> Activity Detection
  --> Fall Detection
             |
             v
      Emergency Verification
             |
             v
        Emergency Manager

Health Sensors
  |
  +--> Heart Rate
  +--> SpO2
  --> Temperature
             |
             v
       Health Monitor
             |
             v
    Health Emergency Handler
             |
             v
    Emergency Verification

Emergency System
  |
  +--> Voice Verification
  +--> Incident Logging
  +--> Notification Interface
  +--> Hospital Interface
  --> Emergency Service Interface

Database
  |
  --> SQLite Incident History

Dashboard
  |
  --> Streamlit Monitoring Interface

NOTE
====

The ESP32 and health sensors are currently simulated in software.
The system is a software demonstration and is not a medical
diagnostic system or a replacement for professional medical care.
